# Vanilla JS Calculator

🔗 **Live demo:** https://amal-thomas-dev.github.io/vanilla-js-calculator/

A responsive, keyboard-accessible calculator built with vanilla HTML, CSS, and JavaScript. No frameworks, no build step.

## Features

- Basic arithmetic (`+`, `−`, `×`, `÷`) with left-to-right chaining
- Decimal input, backspace, and full clear
- Graceful handling of divide-by-zero and out-of-range results
- Long decimals rounded to fit the display
- Full keyboard support: `0–9`, `+ - * /`, `.`, `Enter`, `Backspace`, `Esc`
- Accessible: `aria-live` display, focus-visible rings, reduced-motion support
